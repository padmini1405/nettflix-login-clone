## Netflix Login and Dashboard Clone

This project is a simple full stack application that replicates a basic Netflix style login page and dashboard. It is built using React for the frontend and Node.js with Express for the backend. The project demonstrates form handling, API communication, simple authentication, and UI design.

## Project Overview

The application includes a login page with a Netflix inspired design and a dashboard page that displays movie rows similar to Netflix. The backend validates user credentials using mock data and returns appropriate responses.

## Features

- Responsive Netflix style login page
- Frontend form validation for email and password
- Backend API for login authentication
- Error handling for invalid login attempts
- Successful login redirects to dashboard
- Simple Netflix style dashboard with movie rows
- Clean and minimal UI using plain CSS

## Technologies Used

Frontend
    - React
    - Axios
    - React Router DOM
    - CSS

Backend
    - Node.js
    - Express
    - CORS

## How It Works

- The user enters email and password on the login page
- Frontend validates input fields
- Data is sent to backend using Axios
- Backend checks credentials against mock data
- If valid user is redirected to dashboard
- If invalid an error message is shown
